## Dealerships Application Overview
Cars Dealership is a national car dealership retailer web application built as part of the IBM Full Stack Software Developer Capstone Project (`fullstack_developer_capstone`).

The application features:
- A Django backend handling user management, authentication, and car models.
- A Node.js and MongoDB backend microservice managing dealerships and customer reviews.
- A Python/Flask microservice analyzing sentiment of customer reviews.
- A React frontend providing responsive views, state filters, and review submission forms.
- Full CI/CD automation with GitHub Actions and deployment via cloud containers.
