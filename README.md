# Cars Dealership Application

**Repository Name:** `xrwvm-fullstack_developer_capstone`  
**Project Name:** Cars Dealership Review Portal

## Overview
Cars Dealership is a cloud-native full-stack web application designed for a national car retailer in the United States. The platform enables customers to browse dealership branches across all 50 states, filter dealers by location, view real-time inventory and vehicle details, inspect customer reviews enhanced with sentiment analysis, and submit dealership reviews.

## Architecture & Technology Stack
- **Frontend:** React.js, HTML5, CSS3, Bootstrap 5
- **Backend Framework:** Django (Python 3) & SQLite
- **Dealership & Review Microservice:** Node.js, Express.js, MongoDB / Mongoose
- **Sentiment Analysis Microservice:** Python, Flask, NLTK SentimentIntensityAnalyzer
- **DevOps & Cloud:** Docker, GitHub Actions CI/CD, Kubernetes, IBM Cloud Code Engine
